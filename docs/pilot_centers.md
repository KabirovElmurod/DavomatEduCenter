# Pilot Markaz bilan Kelishuv

## Maqsad

3-5 ta o'quv markaz bilan suhbat o'tkazib, ularning ehtiyojlarini tushunib, 1 ta pilot markaz bilan kelishuvga erishish.

## Suhbat Savollari

### 1. Umumiy Ma'lumotlar
- Markaz nomi
- O'quvchilar soni
- Ustozlar soni
- Guruhlar soni
- Dars jadvali (haftada necha kun)
- Hozirgi davomat qanday qilinadi?

### 2. Oqiyotgan Muammolar
- Ustozlar davomatni qanday yozadi? (qog'oz, Excel, WhatsApp)
- Ota-onalar davomatni qachon biladi? (kun oxiri, ertasi, hech qachon)
- Ota-onalar shikoyat qiladimi? ("Farzandim keldimi kelmadi?")
- Ustozlar shikoyat qiladimi? ("Xabar yuborishga vaqt yo'q")
- Admin shikoyat qiladimi? ("Hisobot yig'ish qiyin")

### 3. Davomat Oqimi
- Ustozlar darsdan keyin qachon davomat yozadi?
- Ota-onalar qachon xabarni kutadi? (dars tugagandan so'ng, kechqurun, ertasi)
- Ota-onalar javob beradimi? ("Keldi" deb tasdiqlash)
- Ota-onalar bir nechta farzand bor bo'lsa?
- Bir nechta ota-ona bir farzand uchunmi? (ota + ona)

### 4. Ota-ona Onboarding
- Ota-onalar bilan qanday aloqa? (WhatsApp, Telegram, telefon)
- Ota-onalar botni qo'llashadi? (smartphone borligi)
- Ota-onalar Telegram'dan foydalanadimi?
- Ota-onalar ingliz tilini tushunadimi? (interface o'zbekcha)
- Ota-onalar QR code yoki havolani afzal ko'radi?

### 5. Ustoz Onboarding
- Ustozlar smartphone borligi?
- Ustozlar Telegram'dan foydalanadimi?
- Ustozlar Android yoki iPhone?
- Ustozlar qancha guruhda ishlaydi?
- Ustozlar kuniga necha dars o'tadi?

### 6. Admin/Owner Onboarding
- Admin smartphone borligi?
- Admin brauzerda ishlashga rozimi?
- Admin Telegram Login Widget'dan foydalanishga rozimi?
- Admin o'quvchilarni qo'shish uchun qancha vaqt sarflaydi?
- Admin guruhlarni boshqarish uchun qancha vaqt sarflaydi?

### 7. Integratsiya
- Hozir qanday tizim ishlaydi? (Excel, boshqa CRM)
- Ma'lumotlarni import qilish kerakmi? (o'quvchilar ro'yxati)
- Ma'lumotlarni export qilish kerakmi? (hisobotlar)
- Boshqa integratsiya kerakmi? (to'lov, hisobot)

### 8. Narx va To'lov
- Pilot davrida bepul bo'ladimi?
- Narx qancha bo'lishi mumkin? (oylik, o'quvchi uchun, guruh uchun)
- Feature qo'shish narxi? (hisobotlar, to'lov)

### 9. Pilot Shartlari
- Pilot davri qancha bo'lishi kerak? (2 hafta, 1 oy)
- Qancha guruhni pilotga qo'shish kerak? (barchasi, bir nechta)
- Qancha ustozni pilotga qo'shish kerak? (barchasi, bir nechta)
- Qancha o'quvchini pilotga qo'shish kerak? (barchasi, bir nechta)
- Feedback qachon olish kerak? (har kuni, har hafta)

### 10. MVP'dan Keyin
- Qaysi feature birinchi navbatda kerak? (to'lov, hisobotlar, Excel)
- Qaysi feature kerak emas? (oz foydalaniladigan)
- Ustozlar qanday feature xohlaydi?
- Ota-onalar qanday feature xohlaydi?
- Admin qanday feature xohlaydi?

## Pilot Markaz Tanlash Mezonlari

### Yaxshi Candidate:
- ✅ O'quvchilar soni: 50-200 (ko'p emas, kam emas)
- ✅ Ustozlar soni: 5-20 (ko'p emas, kam emas)
- ✅ Guruhlar soni: 10-30 (ko'p emas, kam emas)
- ✅ Ustozlar smartphone borligi: 80%+
- ✅ Ota-onalar smartphone borligi: 70%+
- ✅ Admin brauzerda ishlashga rozimi
- ✅ Pilot davriga rozimi (2 hafta)
- ✅ Feedback berishga rozimi
- ✅ Muammolari bor (shikoyat qiladi)

### Yomon Candidate:
- ❌ O'quvchilar soni: < 20 (juda kam)
- ❌ O'quvchilar soni: > 500 (juda ko'p)
- ❌ Ustozlar smartphone yo'q (50%+)
- ❌ Ota-onalar smartphone yo'q (60%+)
- ❌ Admin brauzerda ishlashni xohlamaydi
- ❌ Pilot davriga rozimas
- ❌ Feedback berishni xohlamaydi
- ❌ Muammolari yo'q (hursand)

## Pilot Markaz bilan Kelishuv

### Shartnoma (Verbal or Written)

**Markaz majburiyatlari:**
1. Pilot davri: 2 hafta
2. Barcha ustozlar WebApp'dan foydalanadi
3. Ota-onalar botni start qiladi (admin invite beradi)
4. Har kuni feedback beradi (yoki har hafta)
5. Bug va muammolarni darhol xabar qiladi

**Developer majburiyatlari:**
1. MVPni deploy qiladi (staging)
2. Onboarding yordam beradi (owner, ustozlar, ota-onalar)
3. Kunlik monitoring (failed notifications, errors)
4. Birinchi 3 kun yonida turish
5. Keyin 11 kun remote support
6. Pilot oxirida final feedback

**Pilot oxirida:**
- Markaz qarori: Davom etish yoki tugatish
- Agar davom etishsa: Narx kelishuvi
- Agar tugatilsa: Feedback va sabab

## Feedback Collection

### Kunlik (Yoki Har Hafta)
- Davomat belgilaydimi? (ha/yo'q)
- WebApp ishladimi? (ha/yo'q)
- Ota-onalar xabarni oldimi? (ha/yo'q)
- Xatolar bormi? (ha/yo'q - qaysi?)
- Shikoyatlar bormi? (ha/yo'q - qaysi?)

### Final Feedback (Pilot Oxirida)
- Ustozlar o'zlari ishlatyaptimi? (ha/yo'q)
- Ota-onalar xabarlarni o'qiydimi? (ha/yo'q)
- Admin panel foydaliymi? (ha/yo'q)
- Qaysi feature kerak? (1, 2, 3)
- Qaysi feature kerak emas? (1, 2, 3)
- Narx qancha bo'lishi mumkin? (oylik)
- Davom etishni xohlaysizmi? (ha/yo'q - nima uchun?)

## Success Metrics

### Pilot davomida:
- Davomat belgilash rate: 90%+ (darslar 90%+ belgilanadi)
- Ota-ona bot start rate: 80%+ (ota-onalar 80%+ botni start qiladi)
- Ota-ona xabar olish rate: 75%+ (xabarlar 75%+ yetib boradi)
- Failed notification rate: < 5% (xatolar 5% dan kam)
- Ustoz WebApp ishlatish: 100% (barcha ustozlar WebApp'dan foydalanadi)

### Pilot oxirida:
- Ustozlar o'zlari ishlatyaptimi: Ha
- Ota-onalar xabarlarni o'qiydimi: Ha
- Admin panel foydaliymi: Ha
- Davom etishni xohlaysizmi: Ha

## Risklar

### Risk 1: Ota-onalar botni start qilmaydi
- Yechim: Deep link onboarding (qattiq qo'llash)
- Fallback: Admin QR code beradi (ixtiyoriy)

### Risk 2: Ustozlar WebApp'dan foydalanmaydi
- Yechim: Birinchi 3 kun yonida turish
- Fallback: Admin panel'dan davomat belgilash (future feature)

### Risk 3: Admin brauzerda ishlashni xohlamaydi
- Yechim: Suhbat davomida tushuntirish
- Fallback: Mobile-first admin UI (future)

### Risk 4: Pilot davomida xatolar ko'p
- Yechim: Kunlik monitoring, tez fix
- Fallback: Agar kritik bo'lsa, pilot to'xtatish

### Risk 5: Pilot oxirida "yo'q" deydi
- Yechim: Sababni so'rash, feedback olish
- Fallback: Boshqa pilot markaz qidirish
